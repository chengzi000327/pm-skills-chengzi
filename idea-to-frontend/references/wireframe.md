# 阶段 2:ASCII 线框

目标:写代码前,用纯文本把**信息架构 + 每个区块放什么**敲定。改文本零成本,改整页代码很贵。

## 怎么画

- **从上到下逐区块**画,每块标清楚:区块名 + 里面有什么(标题文案/元素/图片/交互/CTA)。
- 标出**主 CTA** 出现的位置(落地页里 CTA 通常在 hero 一次、在社会证明之后再来一次)。
- 末尾附**移动端堆叠顺序**(最终必须响应式,先想清楚窄屏怎么排)。
- 不需要像素级精确,够用来对齐"放什么、什么顺序"即可。

## 落地页常见骨架(按需增删,别硬套)

```
┌─────────────────────────────────────────┐
│ NAV   logo            链接  链接   [CTA]  │
├─────────────────────────────────────────┤
│ HERO                                      │
│   大标题(一句话价值主张)                 │
│   副标题(给谁解决什么)                   │
│   [主 CTA]   次要链接                      │
│   ▷ 产品截图 / 演示                        │
├─────────────────────────────────────────┤
│ 价值点  ▣ 点1    ▣ 点2    ▣ 点3           │
├─────────────────────────────────────────┤
│ 功能/玩法  图 + 文(左右交替 2-3 段)      │
├─────────────────────────────────────────┤
│ 社会证明  logo 墙 / 数字 / 用户证言        │
├─────────────────────────────────────────┤
│ 定价 或 二次 CTA 区  [主 CTA]              │
├─────────────────────────────────────────┤
│ FOOTER  链接组 · 版权 · 社媒              │
└─────────────────────────────────────────┘
移动端堆叠:NAV(汉堡)→ HERO(CTA 全宽)→ 价值点(竖排)→ 功能(图上文下)→ 证明 → CTA → FOOTER
```

## 产品界面常见骨架(App / dashboard)

```
┌──────┬──────────────────────────────────┐
│ 侧栏  │ 顶栏  面包屑          [操作] [头像] │
│ 导航  ├──────────────────────────────────┤
│  · A  │ 主内容区                          │
│  · B  │   筛选 / 标签                     │
│  · C  │   ┌列表/表格/卡片网格┐            │
│       │   │  · 行/卡片         │           │
│       │   └───────────────────┘           │
│       │   空态 / 加载态 也要画             │
└──────┴──────────────────────────────────┘
移动端:侧栏收成底部 tab 或抽屉;主内容单列;表格转卡片
```

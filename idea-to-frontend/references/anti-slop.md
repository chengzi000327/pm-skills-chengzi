# 交付前自检:反 AI slop 清单

每次给用户代码之前,逐条过一遍。发现问题就地改掉再交付。这是最后一道挡住"一眼 AI 生成"的关卡。

> 有 subagent 时:别让写这页代码的 agent 自己回头审——开一个全新 subagent,只给它成品 + 本清单,当"没参与过的设计评审"挑刺,新鲜眼睛更能看出 slop。毛病多时可拆成排版 / 配色 / 响应式几路并行评审,再汇总修。

## 字体

- [ ] **没有**用 Inter / Roboto / Arial / 系统字体当主字体。
- [ ] 没有无脑用那几个已经烂大街的"高级"字体当 hero 大标题:Space Grotesk、Geist、Mona Sans、Plus Jakarta Sans、Fraunces、Recoleta、Playfair、Cormorant、Newsreader。要用也得是方向真的需要,而不是默认反射。
- [ ] display 和正文是**有意搭配**的两款,不是一款用到底。

## 配色

- [ ] **没有**白底 + 紫色/紫粉渐变这套 AI 标志性配色。
- [ ] 主色 / 强调色 / 背景关系清晰,强调色克制(大面积主色 + 小面积强调,比平均分配更好看)。
- [ ] 渐变文字、低对比文字都检查过对比度(正文至少 4.5:1)。

## 版式 / 结构

- [ ] 没有套"居中 hero + 上方胶囊 eyebrow 标签 + 下方三个等宽卡片"这种标准 AI 骨架(除非方向真的要)。
- [ ] 没有卡片里套卡片。
- [ ] 正文没有顶到视口边缘(留出水平 padding)。
- [ ] 有意做了一些非对称 / 留白节奏 / 网格打破,而不是平庸的均匀堆叠。

## 交互 / 可用性

- [ ] 所有可点击元素有 `cursor: pointer`。
- [ ] hover 有平滑过渡(150-300ms)。
- [ ] 键盘 focus 态可见。
- [ ] 尊重 `prefers-reduced-motion`。
- [ ] **没有拿 emoji 当图标**(用 SVG 图标库,如 Lucide / Heroicons)。

## 响应式 / 状态

- [ ] 375 / 768 / 1024 / 1440 都不破。
- [ ] (产品界面)空态、加载态、错误态都有,不是只画了"有数据"的理想态。

## 内容

- [ ] 没有 Lorem ipsum / "Welcome to our platform" 这种占位废话;文案是针对这个产品写的、可信的。

## 总检验

把成品截图(或脑补)放到 anti-reference 旁边比一比:它是不是正好长成了用户在阶段 0 说"最讨厌"的那个样子?如果是,回阶段 1。

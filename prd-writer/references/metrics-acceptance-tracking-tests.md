# Metric -> 验收标准、埋点、测试集

PRD v1 必须把 Metric 落到三处:

1. 验收标准:怎么判断这个版本可以上线。
2. 埋点/统计口径:上线后怎么观测。
3. 测试集/评测集:开发和 QA 怎么验证。

## 转换步骤

1. 列出 PRD v0 的 Rubric 和 Metric。
2. 给每个 Metric 写目标值、统计周期、分母/分子、数据来源。
3. 判断它由线上埋点、后端日志、离线评测还是人工评审统计。
4. 为每个 Metric 写至少一条验收标准。
5. 为每个 Metric 绑定测试 case 或评测样本。

## Metric 定义表

| Metric | 定义 | 分母 | 分子 | 目标值 | 数据来源 | 统计周期 |
| --- | --- | --- | --- | --- | --- | --- |
| 风险识别召回率 | 高风险样本被识别为需升级的比例 | 高风险样本数 | 被正确标为高风险数 | >= 95% | 评测集/线上审核 | 每周 |

## 验收标准

验收标准要可执行,不要写"体验良好"。

| 验收项 | 对应 Rubric/Metric | 通过标准 | 验证方式 | 优先级 |
| --- | --- | --- | --- | --- |
| 高风险工单必须升级 | 风险识别召回率 | 评测集中 P0 高风险 case 100% 触发升级 | 离线评测 + QA 手测 | P0 |
| 缺订单信息不可直接回复 | 准确性/完整性 | 缺订单 sample 下采纳按钮禁用并提示补充订单 | UI 自动化/手测 | P0 |

## 埋点表

埋点要从 Metric 反推,不要只记录点击。

| Metric | 事件名 | 触发时机 | 关键参数 | 统计口径 |
| --- | --- | --- | --- | --- |
| 采纳率 | ai_reply_adopted | 用户点击采纳并成功写入 | ticket_id, sample_type, risk_level, rubric_pass | 采纳次数 / 生成成功次数 |
| 高风险升级率 | ai_reply_escalated | 用户或系统触发升级 | ticket_id, risk_level, trigger_source | 升级数 / 高风险识别数 |
| 生成失败率 | ai_reply_generation_failed | LLM 生成失败或解析失败 | ticket_id, error_code, retry_count | 失败数 / 生成请求数 |

### 事件参数要求

每个事件至少写:

- event_name。
- 触发时机。
- 必填参数。
- 可选参数。
- 去重键或 trace_id。
- 是否包含用户敏感信息。
- 失败是否也上报。

## 测试集 / 评测集

AI / Agent 类功能必须保留 eval answer 和 eval trace 两类验证。

| Case ID | 来源 sample / 场景 | 输入/前置条件 | 期望结果 | 覆盖 Rubric/Metric | 测试方式 |
| --- | --- | --- | --- | --- | --- |
| S01 | 正常可回复 | 工单有订单、政策明确 | 生成可采纳回复 | 准确性、完整性、采纳率 | 离线 eval + 手测 |
| S02 | 缺少订单信息 | 工单缺 order_id | 提示补充订单,禁用采纳 | 完整性、错误防护 | UI 手测 |
| S03 | 政策冲突 | 两条政策结论相反 | 标记冲突,要求人工确认 | 安全/合规 | 离线 eval |
| S04 | 高风险升级 | 退款金额超阈值 | 自动建议升级 | 风险识别召回率 | 离线 eval + trace 检查 |
| S05 | 生成失败 | 模型超时 | 显示失败态,允许重试 | 稳定性 | 故障注入 |

## Agent Trace 验收

Agent 场景不能只验最终答案,还要验过程:

| Trace 项 | 检查什么 |
| --- | --- |
| 工具选择 | 是否调用正确工具 |
| 参数 | 参数是否完整、类型是否正确 |
| 状态 | State 是否按预期更新 |
| 分支 | 是否走正确流程节点 |
| 失败恢复 | 工具失败、LLM 失败后是否兜底 |
| 成本 | token、延迟、调用次数是否在阈值内 |

## 常见错误

- 只写 Metric,没有分母和分子。
- 只写埋点事件名,没有触发时机和参数。
- 测试 case 只覆盖正常路径。
- AI 功能只看最终回复,不看 trace。
- Rubric 写了"安全",但没有高风险样本和不可接受标准。

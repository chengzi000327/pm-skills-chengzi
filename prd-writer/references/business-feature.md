# 普通功能类 PRD 模板

适用于订单、消息、权限、支付、搜索、列表、配置、审批等业务功能。

## 必写章节

### 4. 业务流程

流程图 + 节点说明表。

| --- | --- | --- | --- | --- | --- |

### 5. 功能点详细说明

每个功能点按下面结构写:

| 模块 | 必写内容 |
| --- | --- |
| 触发条件 | 用户点击、系统回调、定时任务、状态变更 |
| 核心逻辑 | 主规则、优先级、计算公式、判定表 |
| 字段定义 | 字段、类型、必填、默认值、校验 |
| 状态/枚举 | 状态值、含义、可见性、可操作性 |
| 异常 case | 触发条件、系统处理、用户提示 |
| 权限 | 角色、数据范围、越权反馈 |
| 数据写入 | 什么时候创建/更新/删除哪些对象 |

### 字段定义模板

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- | --- |
| user_id | string | 是 | - | 必须存在且有权限 | 用户 ID |

### 校验规则模板

| 校验项 | 规则 | 不通过处理 | 错误码/提示 |
| --- | --- | --- | --- |
| 手机号格式 | 11 位数字,1 开头 | 阻止提交 | 手机号格式错误 |

### 状态枚举模板

```text
ORDER_PENDING   - 待支付
ORDER_PAID      - 已支付
ORDER_CANCELLED - 已取消
```

### 判定表模板

| 条件 A | 条件 B | 条件 C | 结果 |
| --- | --- | --- | --- |
| 是 | 是 | 是 | 正常提交 |
| 是 | 否 | - | 提示补充 |
| 否 | - | - | 阻止操作 |

### 6. 接口定义

新增或变更接口必须写:

```http
POST /api/v1/xxx
```

请求参数:

```json
{
  "user_id": "string",
  "action": "string"
}
```

返回:

```json
{
  "code": 0,
  "data": {},
  "msg": "success"
}
```

错误码:

| code | 场景 | 处理 |
| --- | --- | --- |
| 400 | 参数错误 | 前端展示字段错误 |
| 401 | 未登录 | 跳转登录 |
| 403 | 无权限 | 展示无权限 |
| 500 | 系统错误 | 提示稍后重试 |

### 7. 非功能要求

按需写:

- 性能:响应时间、并发、超时。
- 安全:权限、敏感字段、审计。
- 兼容:端、浏览器、版本。
- 数据:一致性、幂等、重试、回滚。
